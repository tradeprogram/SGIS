# Stage2 모델 선택 — 검증셋 지표가 운영지표로 옮겨가지 않은 사례

## 요약

연구실 v4b 방법론(Stage1 LGBM 1:20 + Stage2 CNN)을 전국 격자 운영 파이프라인에
이관했더니, 검증셋 AUROC 는 올랐는데 **실제 발화 지점을 상위 1% 안에 넣는 비율은
5.3% → 2.9% 로 거의 반토막**이 났다. 원인을 분리한 결과 4분의 3이 아키텍처(GRU→CNN)
교체에서 나왔다. 배포 파이프라인은 GRU 를 유지한다.

## 왜 두 지표가 엇갈리는가

AUROC 는 격자 403,385개 순위 전체의 평균적 분리도다. 화면에 쓰는 "우선대응 상위 1%"
는 그중 꼬리 4,034셀의 순서만 본다. 순위 중간이 아무리 잘 정렬돼도 꼭대기가 흐트러지면
AUROC 는 거의 안 움직이고 운영지표만 무너진다. 실제로 그렇게 됐다.

출력 포화로 동점이 생겨 꼬리가 뭉개진 것은 아니다. 확인해 보니 CNN 출력의 고유값이
366,984개이고 상위 1% 내 동점은 9개뿐이었다.

## 실험 설계

Stage1(구 LGBM → r20)과 Stage2(GRU → CNN)가 동시에 바뀌어 있어 원인이 섞여 있었다.
같은 데이터·같은 재표본화(1:20)·같은 하이퍼파라미터(dropout 0.2, lr 5e-4, batch 2048,
patience 15)로 GRU 를 학습해 중간 조건을 만들었다. GRU 원래 설정(dropout 0.3, lr 3e-4)
을 쓰면 아키텍처 차이와 하이퍼파라미터 차이가 다시 섞이므로 CNN 쪽에 맞췄다.

| | Stage1 | Stage2 | 학습 |
|---|---|---|---|
| A | 구 LGBM | GRU | 구 하네스 (현행 배포) |
| B | r20 | GRU | 62번 하네스, 1:20 |
| C | r20 | CNN | 62번 하네스, 1:20 |

`B vs C` = 아키텍처분, `A vs B` = Stage1 교체분.

## 결과

### 5개 연도 전수 — A vs C (발화 1,160건, 스캔시각 11·14시 통제)

| 구간 | A 구GRU | C CNN+r20 | 차이 |
|---|---|---|---|
| 상위 1% 이내 | **5.3%** | 2.9% | −2.4%p |
| 상위 5% 이내 | **15.3%** | 10.9% | −4.4%p |
| 상위 10% 이내 | **22.9%** | 18.8% | −4.1%p |
| 상위 20% 이내 | **34.7%** | 31.8% | −2.8%p |

개선 457건 / 악화 610건. 5개 연도 전부 악화.

### 원인 분리 — 2022년 343건 (회귀가 가장 컸던 해)

| 구간 | A 구GRU | B GRU+r20 | C CNN+r20 |
|---|---|---|---|
| 상위 1% 이내 | 5.2% | **5.8%** | 2.6% |
| 상위 5% 이내 | **14.0%** | 12.8% | 9.6% |
| 상위 10% 이내 | **23.0%** | 21.3% | 16.3% |
| 상위 20% 이내 | **36.7%** | 32.1% | 29.7% |

상위 10% 기준 분해

| 구간 | 기여 |
|---|---|
| A → B  Stage1 교체분 | −1.7%p |
| B → C  아키텍처분 | **−5.0%p** |
| A → C  합계 | −6.7%p |

승패로 봐도 같다. `B vs A` 149:172 (동전던지기), `C vs B` 125:196 (명확한 악화).

### 검증셋에서도 동일 조건이면 GRU 가 낫다

교수님 CSV 의 CNN 우위는 GRU 와 같은 조건에서 비교된 적이 없었다. 같은 데이터·같은
재표본화·같은 하이퍼파라미터로 맞추면 검증셋 AUROC 부터 뒤집힌다.

| 조건 | t+1h AUROC (연도 전체) |
|---|---|
| B GRU + r20 + 1:20 | **0.8880** |
| C CNN + r20 + 1:20 | 0.8843 |

## 결론

1. **배포 파이프라인은 GRU 유지.** CNN 이관은 하지 않는다.
2. **Stage1 r20 은 중립.** 상위 1% 에서는 오히려 개선(5.2→5.8%)이지만 상위 5~20% 와
   대형산불(중앙 5.8→8.9%)에서 밀려 합치면 이득이 없다. 5시간 재스캔 값을 못 한다.
3. 코드는 `STAGE2_ARCH` / `STAGE2_RATIO` 로 세 조건을 다 돌릴 수 있게 남겨 둔다.
   가중치와 산출물은 접미사로 분리돼 있어 언제든 재현된다.

## 한계

- 3-way 분리는 2022년 343건에서만 했다. 5개 연도 전수는 A vs C 만 있다.
- 조건 B 의 대형산불 표본은 11건이라 그 항목은 결론으로 쓰기 어렵다.
- CNN 재학습은 교수님 Colab 노트북 없이 CSV 행 수에서 설정을 역산해 재구성한 것이다.
  1:10 으로 재현했을 때 평균 AUROC 0.8830 vs 원본 0.8884 (−0.0054) 로 근접하지만
  dropout·시드·early-stop 기준은 여전히 추정값이다. 이 차이가 결과를 뒤집을 만큼
  크지는 않다고 보지만, 원본 설정으로 다시 확인할 여지는 남아 있다.
